Which organisation do you want an API token for?

API tokens are organisation-specific. Select the organisation you want to generate a token for. You can only get an API token for organisations you have permissions for.

From there, go to the OAuth & permissions tab and select Rotate secret to generate a new client secret. This client secret is your API token.
