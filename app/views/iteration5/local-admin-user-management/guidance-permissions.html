This collection allows the API to automate submissions. This is a one-off setup and is only needed if submissions are made programmatically. See the API submission guidance for full instructions or follow the instruction below.

Setting up an API submission for LCSDS

How to get an API token

Click Get an API token below to open the API management application.

API tokens are organisation-specific. Before you are redirected to the application, you will be asked to confirm which organisation you want the token for. Make sure you select the correct organisation, as the token will only be valid for submissions made on behalf of that organisation.

Go to OAuth & permissions and select Rotate secret to generate a new client secret. This client secret is your API token.
Keep your API token secure, as it allows submissions on behalf of your organisation.

Other settings

When submitting via the API, you must also provide a submission type and a submission window ID.
